# Test data

Public data only.

- `mykrobeshig_example/`: mykrobeshig's own `example_data` (ERR047239,
  SRR7223147 JSONs and `example_output_predictResults.tsv`), from
  ShigellaGenomics/mykrobeshig commit 4c7521b (GPL-3.0). Used to check the
  vendored parser reproduces upstream exactly.
- `mykrobe_json/`: Mykrobe 0.13.0 JSON results (bundled panels) from the
  Phase 0 validation runs on public SRA reads (see `validation/accessions.tsv`):
  SRR8117834 (S. sonnei CipR.MSM5, Hawkey 2021), SRR4192076 (S. flexneri 2a,
  Flex-It), SRR4787878 (E. coli, Flex-It media-6), SRR5306599 (S. boydii,
  Flex-It media-6); each run with both schemes. BioProjects: PRJNA315192,
  PRJNA218110.
